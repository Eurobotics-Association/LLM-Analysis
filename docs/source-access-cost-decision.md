# Urgent source access and cost decision

**Checked 3 November 2026.** Related to [issue #16](https://github.com/Eurobotics-Association/LLM-Analysis/issues/16) and draft PR #17. No subscription, API calls, external contact, or chart publication.

## Artificial Analysis: paid Pro, useful but not yet a proven solution

[Official pricing](https://artificialanalysis.ai/pricing) displays **$417/month per seat** on its current monthly/yearly selector and says yearly billing saves $984. The page's rendered text does not unambiguously expose which billing option is selected; verify the payable monthly and annual amounts at checkout. A [third-party report](https://techpilot.ai/tools/artificial-analysis/) says $499/month or $417/month billed annually, but this is secondary and should be confirmed with AA. AA states no free trial, offers academic discounts on inquiry, and asks users to contact it for external use or redistribution.

There is also a [free API](https://artificialanalysis.ai/data-api/docs) with a key: headline indices, basic price and performance and 100 requests per 24-hour window. Free registration does not grant Pro data. [AA's API documentation](https://artificialanalysis.ai/data-api/docs/reference) says Pro supplies overall Intelligence Index token counts and per-evaluation token counts on model-detail endpoints; its sample fields include input, answer, output and reasoning tokens. This directly improves feasibility. However the public schema/example does not establish per-call cache read/write/TTL, request context tier, actual evaluation provider and full retry/helper usage; the provider breakdown is Commercial-only. Reasoning is included in output in the sample, not additive. Thus Pro does **not yet prove** it will enable compliant OpenRouter repricing. AA says it aims to benchmark leading models within 24 hours of release, not a guarantee.

Before any purchase, request written confirmation or a redacted example covering: exact billed uncached/read/write categories for each model/effort/evaluation and whether per-request context thresholds are available; provider/quantization and retry/helper scope; whether figures are raw or derived from typical cache behavior; whether the data support recalculation against an alternative OpenRouter provider; and whether a public Eurobotics chart, derived scores and source data redistribution are licensed. [AA's own methodology](https://artificialanalysis.ai/methodology/intelligence-benchmarking) combines usage with live typical cache-hit measurements. A paid plan alone does not validate alternative-provider cache assumptions.

## Vals: best recent public candidate, not yet OpenRouter-repriceable

[Terminal-Bench 4.0](https://www.vals.ai/benchmarks/terminal-bench-4) displayed an October 29 update when checked November 3, with 66 tasks, three runs per task and a shared mini-swe-agent harness. It includes GPT-6.1 Sol/Terra, GPT-6 Astra, Claude, Gemini, GLM and DeepSeek, with selected effort comparisons. The task success score is for a defined terminal-agent benchmark, not an overall general Intelligence Index. A recent update is not a documented cadence guarantee.

Direct [trajectory viewer](https://www.vals.ai/benchmarks/terminal-bench-4/trajectories) inspection, documented in [the matched audit](vals-matched-trajectory-audit.md), confirms per-step input/output, reasoning and rounded cached percentages for GPT-6.1 Sol and DeepSeek V4.1 Flash 1017 on a common displayed task. Exact cache categories, write TTL, actual provider, fallback/helper billing, effort coverage and permitted bulk export remain unverified. The published cost/test is Vals' figure, not verified OpenRouter. [Vals' open benchmark service](https://github.com/vals-ai/terminal-bench-benchmark-service) pins Terminal-Bench 4.0 tasks and verifier images; publishing a harness is not evidence the scored billing ledger is open. No paid account is shown to be necessary to view the public leaderboard; exact data access was not established.

## SKYEVAL: general index and reported cost, older snapshot inspected

The [Chinese SKYEVAL leaderboard](https://skyeval.com/sla/leaderboard?type=official) inspected November 1 showed a September 2026 report and a 2026-09-02 selector. It includes model-family comparisons, a weighted agent/coding/general/reasoning composite, aggregate tokens, and reported RMB evaluation costs. This is a promising independent comparison to AA but its public report is not evidence of OpenRouter pricing. Current update cadence, exact inputs/output/cache categories, all effort settings, provider/quantization, billable retries and a machine-readable scored-run ledger remain unverified. The rendered page was not retrievable in the browsing tool on November 3; the September observation is not proof no newer release exists.

SKYEVAL's separate [QwenClawBench](https://github.com/SKYLENAGE-AI/QwenClawBench) offers a 100-task agent benchmark and efficiency calculation code. Its [leaderboard](https://skylenage-ai.github.io/QwenClawBench-Leaderboard/) shows 12 models including GPT-5.4 high and GLM 5.1; modern GPT-6.1 coverage is not established. Its [dataset](https://huggingface.co/datasets/skylenage-ai/QwenClawBench) is gated by contact-information sharing; no access was obtained. This is distinct from SKYEVAL's composite leaderboard, and open code does not establish that complete per-call billing records are public.

## Recommendation and practical decisions

1. Keep COSPA as a historical proof-of-concept, not the update source.
2. Use Vals for a **technical task success reference**, and SKYEVAL as a separate general-capability cross-check. Do not mix their score scales.
3. For an urgently useful **OpenRouter task-cost chart**, none of the examined free sources is yet verified complete. Prioritize asking AA and Vals for a schema/sample and reuse permission, and SKYEVAL for dates, exact usage categories and provider provenance. Do not send messages without explicit user instruction. Draft questions above are ready for the maintainer.
4. Do not buy AA Pro solely on the assumption that it solves the problem; get field-level and external-publication confirmation first. If those answers are positive, evaluate the true subscription cost against project budget. If not, a separately agreed Vals-priced reference chart or a small newly instrumented OpenRouter benchmark would be separate decisions.

OpenRouter-only pricing and omission of unverified task-cost points remain binding. Existing chart and main are untouched. Issues are open for corrections.
