# Chinese-language evaluation source: SKYEVAL

**1 November 2026.** Research follow-up for [#16](https://github.com/Eurobotics-Association/LLM-Analysis/issues/16) and draft PR #17. No chart or pricing policy changes.

[SKYEVAL / 晓天衡宇](https://skyeval.com/sla/leaderboard?type=official) is a concrete source that previous research missed. Its official LLM leaderboard, inspected in a browser, calls the visible snapshot the **September 2026** leaderboard, with a displayed selector value of 2026-09-02. It states that it covers 20+ benchmark datasets in four weighted categories: agentic 35%, coding 25%, general 15%, reasoning 25%. Examples listed include SWE-bench Multilingual, Terminal-Bench-Pro, LiveCodeBench V6, SciCode and BrowseComp-ZH. The platform says its scores and analysis are periodically updated, but an actual guaranteed publication cadence, model run dates, and the latest available snapshot were not established; the displayed date must not be described as current coverage.

The site contains a **model capability versus inference cost** section, described as the total inference cost of its evaluation in RMB, and an aggregate token-use chart. Its generated textual summary gives GLM 5.3 at 68.10 and RMB 5,363, DeepSeek V4 Flash at 64.06 and RMB 938, and GPT-5.5 at RMB 82,688. These are the site's own reported figures, on its own composite and workload, not verified OpenRouter costs or cost per task. The component score, total workload and unit need source verification before drawing comparisons; generated summaries and exact task coverage require audit. Such numbers are not evidence of AA bias. Direct links to the interactive page and [source search rendering](https://skyeval.com/sla/leaderboard?type=official).

This is closer to the requested capability-versus-actual-evaluation-cost view than a price-per-token site. It compares Chinese and Western models, identifies open/closed weights, and publishes its category weights. It is a complementary general benchmark, not directly interchangeable with Vals Terminal-Bench scores. As reported by [Alibaba's data-evaluation announcement](https://readance.app/articles/live-art_25bd45aec350472789abee18348c90e5/), SKYEVAL has an Alibaba connection; account for this when assessing independence. [Its GitHub organization](https://github.com/SKYLENAGE-AI) publishes tools and separate benchmark projects. Its [QwenClawBench benchmark code](https://github.com/SKYLENAGE-AI/QwenClawBench/blob/main/scripts/benchmark.py) computes task efficiency metrics; this does not establish that its raw logs or methods match the main SKYEVAL leaderboard. QwenClawBench's [Hugging Face dataset](https://huggingface.co/datasets/skylenage-ai/QwenClawBench) is gated behind contact-information sharing; it was not accessed.

**Unverified:** public per-attempt score, actual evaluation model/provider/quantization, reasoning effort, uncached input, cache read/write, tier and all billable retries; the current update cadence and detailed source prices are likewise unconfirmed. Thus this candidate cannot currently supply verified OpenRouter-repriced task-cost points. No inference may be drawn that its reported RMB expenditure used eligible OpenRouter endpoints.

Other leads: [OpenCompass](https://github.com/open-compass/opencompass), a Chinese evaluation framework, provides broad capability comparisons but a matching billing ledger is unverified; [Tsinghua AgentBench](https://github.com/THUDM/AgentBench) provides open agent-evaluation code but an actively maintained current-model cost series is unverified. [MaaS Daily](https://daily.maas.click/leaderboards/) describes weekly refreshed median coding-agent session costs by harness/model/turn band; these are observational sessions, not the same assigned tasks, and its methodology and source pricing must be checked before interpretation.

Recommended next audit: inspect SKYEVAL's release selector and exact run dates, test model and effort coverage, trace one GPT and one GLM/DeepSeek result through dataset and provider records, look for category-level usage and an authorized machine-readable export, and compare all eligible OpenRouter routes only if those records suffice. Track Vals in parallel; a source is not proven regularly refreshed by its declared intention or a single dated snapshot.
